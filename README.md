# Bryant's Son Home Improvement

Bryant's Son Home Improvement is a full-stack C# and .NET application designed to showcase home improvement services through a customer-facing website, REST API, console client, and automated testing.

The project demonstrates ASP.NET Core development, RESTful API design, CRUD operations, asynchronous programming, API consumption with `HttpClient`, and multi-project .NET solution organization.

---

## Features

- ASP.NET Core Minimal API
- Customer-facing web application
- Console application that consumes the API using `HttpClient`
- Full CRUD operations for home improvement services
- Asynchronous programming with `async` and `await`
- Integration testing with xUnit
- API testing with `WebApplicationFactory`
- JSON serialization and deserialization
- Responsive website structure
- Multi-project .NET solution
